What is Virtualization?
-----------------------
Virtualization is the technology that allows us to create multiple virtual computers (Virtual Machines) on a single physical computer.
Instead of buying 10 physical servers, we can buy one powerful server and divide its resources into multiple virtual servers.
Each virtual server behaves like a completely independent computer.

Types of Hypervisors:
---------------------
There are two major types.

 >>> Type 1 Hypervisor (Bare Metal)
-----------------------------------
Runs directly on the hardware.
 . Applications
 . Operating System (Guest)
 . Hypervisor
 . Hardware

Examples
 . VMware ESXi
 . Microsoft Hyper-V (Server installation)
 . Xen

Advantages
 . Faster
 . More secure
 . Better performance
 . Used in data centers and cloud environments

Type 2 Hypervisor (Hosted Virtualization)
-----------------------------------------
Hosted virtualization means the hypervisor runs on top of an existing operating system instead of directly on the hardware.

Architecture:
 . Applications
 . Guest OS
 . Hypervisor
 . Host Operating System
 . Hardware

Examples
 . Oracle VM VirtualBox
 . VMware Workstation

Example
Your laptop:
Windows 11 (Host OS)

Install VirtualBox.

Create:
 . Ubuntu VM
 . Kali Linux VM
 . Windows Server VM

Here:
 . Windows = Host OS
 . VirtualBox = Hypervisor
 . Ubuntu = Guest OS

Advantages
 . Easy to install
 . Great for learning
 . Good for development and testing

Disadvantages
 . Slightly slower because requests go through the host operating system
 . Depends on the host OS being stable

What is Nested Virtualization?:
-------------------------------
Nested virtualization means running a hypervisor inside a virtual machine, allowing that VM to create and run its own VMs.

Think of it as:
Physical Server
↓
Hypervisor
↓
Virtual Machine
↓
Another Hypervisor
↓
Another Virtual Machine

Example:
Laptop
↓
VirtualBox
↓
Ubuntu VM
↓
Install KVM inside Ubuntu
↓
Create another Ubuntu VM

A VM is now hosting another VM.

Why is Nested Virtualization Used?
----------------------------------
 . Learning virtualization technologies
 . Hypervisor development and testing
 . Cloud platform testing
 . Kubernetes or lab environments that need virtual machines
Cloud providers such as AWS, Azure, and GCP support nested virtualization only on selected VM families and configurations.

Hosted Virtualization vs Nested Virtualization:
-----------------------------------------------
| Feature             | Hosted Virtualization                   | Nested Virtualization                             |
| ------------------- | --------------------------------------- | ------------------------------------------------- |
| Purpose             | Run VMs on a desktop or laptop          | Run VMs inside another VM                         |
| Host                | Physical machine with a Host OS         | A virtual machine                                 |
| Hypervisor Location | Installed on the Host OS                | Installed inside a guest VM                       |
| Performance         | Generally good for development          | Additional performance overhead                   |
| Complexity          | Easy                                    | Advanced                                          |
| Common Use          | Learning, testing, software development | Hypervisor testing, cloud labs, advanced training |

Difference between VirtualBox / WSL:
	VirtualBox and WSL are fundamentally different technologies, even though both let you run Linux on a Windows machine.

VirtualBox
-----------
Oracle VM VirtualBox is a Type 2 (Hosted) Hypervisor.
It creates a complete Virtual Machine (VM) with virtual hardware.

Architecture:
 . Applications
 . Ubuntu OS (Guest)
 . VirtualBox
 . Windows (Host OS)
 . Physical Hardware

The Ubuntu VM has:
 . Its own kernel
 . Own RAM
 . Own virtual CPU
 . Own virtual disk
 . Own virtual network card
 . Own boot process
It behaves exactly like a separate physical computer.

Example

Your laptop:
Windows 11
16 GB RAM

Create:
Ubuntu VM
4 GB RAM
2 CPUs
100 GB Disk

Ubuntu thinks it is installed on a real computer.

Advantages
 . Complete isolation
 . Run almost any operating system
 . Great for learning servers
 . Can simulate enterprise environments
 . Snapshots
 . Clone VMs

Disadvantages
 . Uses more RAM
 . Uses more CPU
 . Slower boot
 . Larger disk usage

WSL (Windows Subsystem for Linux)
---------------------------------
Windows Subsystem for Linux is not a traditional hypervisor like VirtualBox.
Its goal is to let Linux applications run seamlessly on Windows.
There are two versions.

WSL 1:
WSL 1 does not use virtualization.
Instead, it translates Linux system calls into Windows system calls.

Architecture:
 . Linux Applications
 . WSL Translation Layer
 . Windows Kernel
 . Hardware

There is no real Linux kernel.

WSL 2:
WSL 2 does use virtualization, but not in the same way as VirtualBox.
It runs a lightweight virtual machine using Microsoft Hyper-V.

Architecture:
 . Linux Applications
 . Linux Kernel
 . Lightweight VM
 . Hyper-V
 . Windows
 . Hardware

Microsoft ships a real Linux kernel inside that lightweight VM.
Unlike VirtualBox, you don't manually create virtual hardware or install the OS from an ISO.

VirtualBox vs WSL 2:
--------------------
| Feature              | VirtualBox                                      | WSL 2                                           |
| -------------------- | ----------------------------------------------- | ----------------------------------------------- |
| Technology           | Type 2 Hypervisor                               | Lightweight VM using Hyper-V                    |
| Full Virtual Machine | ✅ Yes                                          | Internally yes, but managed automatically       |
| Install Linux ISO    | ✅ Yes                                          | ❌ No                                          |
| Separate BIOS/Boot   | ✅ Yes                                          | ❌ No                                          |
| GUI Linux Desktop    | ✅ Easy                                         | Possible but not the primary purpose            |
| Performance          | Good                                            | Usually faster for development workloads        |
| Resource Usage       | Higher                                          | Lower                                           |
| Best For             | Learning servers, networking, OS administration | Software development, scripting, Docker, DevOps |

Can WSL Replace VirtualBox?
---------------------------
It depends on your goal.
If you're learning Linux commands
WSL 2 is often enough.

You can practice:
 . Shell scripting
 . Git
 . Docker
 . Kubernetes CLI
 . Terraform
 . Ansible
 . Python
 . DevOps tools

If you're learning system administration
Use VirtualBox.

You can practice:
 . OS installation
 . Disk partitioning
 . GRUB bootloader
 . Networking
 . Multiple VMs
 . Firewalls
 . DHCP
 . DNS
 . Active Directory labs

for DevOps
WSL 2 is usually the better choice because many tools integrate well with Windows and Linux together.
For infrastructure labs involving multiple machines or networking scenarios, VirtualBox remains more suitable.

Simple Analogy:
---------------
Imagine learning to drive.
VirtualBox is like owning a complete practice car. You can open the hood, replace parts, install a different engine, or even break the system and rebuild it.
WSL 2 is like having a powerful driving simulator built into your house. It gives you an excellent environment to practice driving, but it doesn't expose every aspect of a real car.

What is an ISO file?
An ISO file (also called an ISO image) is an exact digital copy of an entire CD, DVD, or bootable disk.
Think of it as a virtual DVD stored in a single file.
Instead of inserting a physical DVD into a computer, you provide the ISO file to software like VirtualBox, and it behaves as if a DVD has been inserted.

Real-World Example:
-------------------
Imagine Ubuntu wants to distribute its operating system.

Old Method
They would manufacture DVDs: Ubuntu DVD
Ubuntu DVD
Contains:
✔ Boot Loader
✔ Linux Kernel
✔ Installer
✔ Packages
✔ Drivers
✔ Filesystem
You would insert the DVD into your computer and install Ubuntu.

Modern Method
Instead of shipping a physical DVD, Ubuntu provides:
ubuntu-24.04-live-server-amd64.iso
This ISO contains everything that would have been on the DVD

Why it is called ISO?
The name comes from the International Organization for Standardization ISO 9660 standard.
ISO 9660 defines how data is stored on CDs and DVDs.

So:
ISO = Standardized disk image format
ISO file = Copy of an entire optical disk

What Does an ISO Contain?
-------------------------
An operating system ISO usually contains:
 . Boot Loader (starts the installation)
 . Operating System Kernel
 . Installer Program
 . Device Drivers
 . Software Packages
 . Default Configuration Files
 . File System Structure
Everything needed to install the operating system.

Are there other formats besides ISO?
------------------------------------
Yes, Different platforms use different formats depending on how the operating system is distributed.
| Format   | Used For                    | Example           |
| -------- | --------------------------- | ----------------- |
| `.iso`   | Bootable installation image | Ubuntu, Windows   |
| `.img`   | Raw disk image              | Raspberry Pi OS   |
| `.vhd`   | Virtual Hard Disk           | Microsoft Hyper-V |
| `.vhdx`  | Improved Virtual Hard Disk  | Hyper-V           |
| `.vmdk`  | Virtual machine disk        | VMware            |
| `.vdi`   | Virtual machine disk        | VirtualBox        |
| `.qcow2` | Virtual machine disk        | KVM/QEMU          |
| `.ova`   | Complete virtual appliance  | Prebuilt VM       |
| `.ovf`   | VM configuration package    | VMware/VirtualBox |
