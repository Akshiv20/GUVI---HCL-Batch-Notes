Understanding File Modes:
-------------------------
| Mode  | Meaning | If File Doesn't Exist        |
| ----- | ------- | ---------------------------- |
| `"r"` | Read    | Error                        |
| `"w"` | Write   | Creates a new file           |
| `"a"` | Append  | Creates a new file           |
| `"x"` | Create  | Error if file already exists |

Read Mode (r):
--------------
Read mode is used only to read an existing file.

Suppose you already have:
employees.txt

Contents:
Rahul
Priya
Arun

Python:

print(file.read())
file.close()

Output:
Rahul
Priya
Arun

Real-Time Example
A Linux Administrator wants to read:

What Happens if the File Doesn't Exist?

Python cannot read a file that isn't there.

---------------
Write mode creates a new file or overwrites an existing one.

Example:

↓

Create Mode (x):
----------------

Reading Methods:
----------------
Python provides several ways to read a file.

read()
Reads the entire file.

file = open("employees.txt", "r")
print(file.read())
file.close()

readline()
Reads only one line.

Example file:
Rahul
Priya
Arun

Code:
file = open("employees.txt", "r")
print(file.readline())
file.close()

Output:
Rahul

readlines()
Reads all lines into a list.

file = open("employees.txt", "r")
print(file.readlines())
file.close()

Output:
['Rahul\n', 'Priya\n', 'Arun\n']

Explain that:
\n means a new line character.

file.close()
This releases the file so other programs can use it.

Better Way: with
-----------------
What if I forget to close the file?
Python provides a better method.

with open("report.txt", "r") as file:
    print(file.read())

The moment the block finishes:
Python automatically closes the file.

Why Do Professionals Use with?
------------------------------
Instead of:

file = open("report.txt", "r")
print(file.read())
file.close()

They use:

with open("report.txt", "r") as file:
    print(file.read())

Benefits:
 . Less code.
 . Automatically closes the file.
 . Safer if an error occurs.

Error Handling:
---------------
Suppose:

with open("abc.txt", "r") as file:
    print(file.read())

The file doesn't exist.
Python crashes.

Instead:

try:
    with open("abc.txt", "r") as file:
        print(file.read())

except FileNotFoundError:
    print("File not found.")

Now the program continues gracefully.

Real-Time Project:

import subprocess

commands = [
    "hostname",
    "date",
    "free -h",
    "df -h"
]

with open("health_report.txt","w") as report:

    for command in commands:

        result = subprocess.run(
            command,
            shell=True,
            capture_output=True,
            text=True
        )

        report.write("Command: " + command + "\n")
