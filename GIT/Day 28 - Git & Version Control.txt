Day 28 - Git & Version Control:
===============================
What is Version Control?
Version Control is a system used to track changes made to files over time.

 > Different Types of Version Control
There are three important categories.
 . Local Version Control
Version history exists on the local computer.

Developer Computer
       |
       v
Local Version Database

Problem: collaboration is difficult.

 . Centralized Version Control
There is one central server.

             Central Server
                  |
        +---------+---------+
        |         |         |
      Dev A     Dev B     Dev C

If the central server becomes unavailable, many operations are affected.

 . Distributed Version Control
Every developer gets a complete repository copy.

             Remote Repository
                    |
        +-----------+-----------+
        |           |           |
      Dev A       Dev B       Dev C
       Git          Git         Git

Each developer has:
 . source code
 . history
 . branches
 . commits
Git is a Distributed Version Control System (DVCS).

 . Working Directory:
The Working Directory is where you actually work on your files.

 . Staging Area:
The staging area is where you tell Git:
"These are the changes I want to include in my next commit."

 . Repository:
The repository contains Git's version history.
Git creates a commit.
Each commit represents a point in the project's history.

Why Git is Important in DevOps:
-------------------------------
1. Version History
You can see what changed.
v1 → v2 → v3 → v4

2. Collaboration
Multiple developers can work on the same project.

Developer A ─┐
Developer B ─┼──> Git Repository
Developer C ─┘

3. Rollback
If a new release breaks production:
Git helps identify the previous version of the source code.

Current
v5 ❌

Rollback

v4 ✅

4. Traceability
You can identify:
 . Who changed something?
 . What changed?
 . When was it changed?
 . Why was it changed?
This is extremely useful during incident investigation.
