Variable Naming Rules:
----------------------
This is an important interview topic.

Rule 1:
-------
Must begin with a letter or underscore.

Correct one:
username = "Akshiv"
_server = "Web01"

Wrong one:
1server = "Web01"

Rule 2:
-------
No spaces.

Correct
server_name

Wrong
server name

Rule 3:
-------
Special characters are not allowed.

Wrong
server-name
server$name

Rule 4:
-------
Case Sensitive

name = "Akshiv"
Name = "Preethi"

Different variables.

Best Naming Practice:
---------------------
Avoid

a = "Chennai"
x = "Ubuntu"

Prefer

city = "Chennai"
server_name = "Ubuntu"

Meaningful names make code easier to read.

Variable Naming Styles:

Module 3: Data Types and Operations:
------------------------------------
Different kinds of information require different handling.
That is exactly why Python has Data Types.

What is a Data Type?
A Data Type tells Python what kind of information is stored inside a variable.

Types of Data in Python:
------------------------
| Data Type        | Meaning         | Example    |
| ---------------- | --------------- | ---------- |
| String (`str`)   | Text            | `"Akshiv"` |

| Boolean (`bool`) | True or False   | `True`     |

----------------

Operations in Python:

A condition is a process of checking something is True or False. Based on the result, Python decides what to do next.

Decision Flow:
--------------
           Condition
               │
      True ────┴──── False
        │              │
 Execute Block A   Execute Block B

The (if) statement:
	(if) statement executes a block of code only when the conditions is True.

Syntax:
-------
if condition:
    statement

Notice
 . if
 . condition
 . colon (:)
 . indentation
All are mandatory.

Simple Example:
---------------
age = 20

if age >= 18:
    print("Eligible to Vote")

Output:
Eligible to Vote

------------------
A Linux Administrator wants to know whether disk usage is high.

disk_usage = 85

if disk_usage > 80:

----------------

if temperature > 40:
    print("High Temperature")

if...else Statement:
--------------------
Sometimes we need Python to do something whether the answer is True or False.
The if-else statement executes one block if the condition is True and another block if it is False.

Syntax:
-------
if condition:
    statement
else:
    statement

Example:
--------
age = 15

if age >= 18:
    print("Eligible")
else:
    print("Not Eligible")

Output:
Not Eligible

Linux Example:
--------------
disk_usage = 55

if disk_usage > 80:
    print("Disk Full")
else:
    print("Disk Usage Normal")

if-elif-else:
-------------
Can there be more than two choices?
elif allows Python to check multiple conditions one after another.

Syntax:
-------
if condition:
    statement

elif condition:
    statement

else:
    statement

Example:
--------
marks = 85

if marks >= 90:
    print("Grade A")

elif marks >= 80:
    print("Grade B")

elif marks >= 70:
    print("Grade C")

else:
    print("Fail")

Output:
Grade B

Real-time Cloud Example:
------------------------
cpu = 88

if cpu > 90:
    print("Critical")

elif cpu > 80:
    print("High")

elif cpu > 60:
    print("Moderate")

else:
    print("Normal")

Introduction to Loops:
----------------------
A loop repeats a block of code multiple times until a condition changes or the required repetitions are completed.

Types of Loops:
---------------
Python mainly has 2 loops.
| Loop  | Purpose                                |
| ----- | -------------------------------------- |
| for   | Repeat a known number of times         |
| while | Repeat until a condition becomes False |

for Loop:
---------
A for loop repeats a block of code for each item in a sequence or for a fixed number of iterations.

Syntax:
-------
for variable in sequence:
    statement

Example:
--------
for i in range(5):
    print("Welcome")

Output:
Welcome
Welcome
Welcome
Welcome
Welcome

What is range():
----------------
It generates a sequence of numbers.

Example:
range(5)

Produces
0
1
2
3
4

Notice: 5 is not included.
Because Python counts positions, not human counting.

A Simple Rule for Range:
------------------------
| Code            | Meaning                       |
| --------------- | ----------------------------- |
| `range(5)`      | Repeat 5 times (values: 0–4)  |
| `range(1,6)`    | Count from 1 to 5             |
| `range(10)`     | Repeat 10 times (values: 0–9) |
| `range(2,11,2)` | Count by 2s: 2, 4, 6, 8, 10   |	= count of every 2 numbers but as we mentioned here (11) this will get stopped before 11; that is why we can see the numbers from 2 to 10.

Real-Time Example:
------------------
Suppose a company has five servers.

for server in range(5):
    print("Checking Server", server)

Output:
Checking Server 0
Checking Server 1
Checking Server 2
Checking Server 3
Checking Server 4

while Loop:
-----------
A while loop keeps executing as long as the condition remains True.

Syntax:
-------
while condition:
    statement

Example:
--------
count = 1

while count <= 5:
    print(count)
    count += 1

Output:
-------
1
2
3
4
5

Real-Time Example:
------------------
Suppose you're waiting for a server to start.

server_running = False

while not server_running:
    print("Waiting for Server...")
    break

In a real automation script, the condition would be updated after checking the server status repeatedly.

break Statement:
----------------
break immediately exits the loop, even if more iterations remain.

Example:
--------
for i in range(10):
    if i == 5:
        break
    print(i)

Output:
0
1
2
3
4

When i becomes 5, the loop stops immediately.

Real-Time Example:
------------------
Suppose you're searching for a file.
As soon as you find it, you stop searching.
That's exactly what break does.

continue Statement:
-------------------
continue skips the current iteration and moves to the next one.

Example:
--------
for i in range(6):
    if i == 3:
        continue
    print(i)

Output:
0
1
2
4
5

The number 3 is skipped, but the loop continues.

Real-Time Example:
------------------
Suppose you're checking 100 servers.
One server is under maintenance.
Skip it and continue checking the remaining servers.
That's what continue does.
